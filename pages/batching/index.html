Method · GPU compact operators

Batched GPU line solves

A sixth-order compact derivative produces many independent tridiagonal systems. The GPU works across those systems; each selected grid line remains one direct tridiagonal solve.

Choose a compact-operator direction

What is batched?

On a uniform grid, the compact operator has the same left-hand-side coefficients for every parallel line. One factorization can therefore be reused for the whole batch.

Coalesced access, no main-path transpose

The storage order is arranged so adjacent threads read adjacent line data for the selected pass. Direction-aware indexing keeps the compact-operator path coalesced without an explicit global transpose.
